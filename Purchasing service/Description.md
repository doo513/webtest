# Purchasing Service

사내 비품 구매 내역을 관리하는 **Purchasing Service**입니다.

일반 사용자는 `guest / guest123` 계정으로 로그인할 수 있습니다. 상점에서 일반 상품을 구매할 수 있고, 구매 기록은 구매 원장에 동기화됩니다.

하지만 일반 사용자 크레딧으로는 플래그 상품을 직접 구매할 수 없습니다. 대리구매 화면에는 URL로 내부 요청을 보내는 기능이 남아 있으며, 사용자 활성화 상태도 함께 표시됩니다. 봇 계정은 비활성화되어 있어 일반 로그인은 불가능하지만, 충분한 크레딧을 가지고 있습니다.

대리구매 요청이 어떤 구매자 세션으로 어떤 URL을 호출하는지 확인해 보세요. 일부 상품은 구매 시 기프트 코드를 생성하지만, 화면에는 일반 구매 내역만 표시됩니다.

## 목표

플래그 상품과 연결된 기프트 코드를 찾아 `/redeem`에서 교환하고 플래그를 획득하세요.

## 계정

```text
guest / guest123
```

## 제공 파일

- `public/app.py`: 주요 Flask 라우트와 구매/교환 로직
- `public/data/users.json`: 사용자별 크레딧 정보
- `public/data/products.json`: 상품 정보

## 참고

- 일반 사용자는 플래그 상품을 직접 구매하기에 크레딧이 부족합니다.
- 대리구매 화면의 봇은 기본적으로 비활성화되어 있습니다.
- 봇 계정은 일반 로그인은 불가능하지만 충분한 크레딧을 가지고 있습니다.
- 구매 기록은 같은 팀의 구매 원장에 동기화됩니다.
- 화면에 보이는 표가 응답에 포함된 모든 정보를 의미하지는 않습니다.
